# Glossary

| Term | Meaning |
| --- | --- |
| Retrieval | Find possible candidates before ranking |
| Ranking | Order candidates by predicted value |
| Slate | Final group/order shown to user |
| Feature snapshot | Point-in-time ranking evidence |
| LTR | Learning-to-rank model-backed ranking |
| Propensity | Exposure probability evidence |
| Guardrail | Rule/control that protects quality or safety |
| Kill switch | Operator control to stop bad model/path |
| Delta refresh | Partial feed update after feedback |
| Backpressure | Reducing source usage when unhealthy |
